TinyPaw Maltese - Local PHP Starter

Structure:
- `assets/` : all static assets (css, js, images)
- `templates/` : `header.php`, `footer.php`
- `pages/` : `home.php`, `puppies.php`, `product.php`, `contact.php`
- `data/products.php` : sample product data as PHP array
- `inc/functions.php` : helper functions

How to run locally:
1. Make sure XAMPP is running (Apache + PHP).
2. Open `http://localhost/richescorsos/` in your browser.

Next steps:
- Replace `data/products.php` with your full list or move to a small database.
- Improve styles in `assets/css/style.css` and reuse existing CSS in `assets/css/`.
- Install PHPMailer for reliable email sending.
- Convert `puppy1.html` content into `pages/home.php` or other templates as desired.
